# Виджет банковских операций

## Описание
Проект представляет собой бэкенд-часть для виджета банковского приложения. 
Он умеет фильтровать транзакции по их статусу и сортировать их по дате.

## Функционал
- **Маскировка данных карт и счетов** Функция `get_mask_card_number` и `get_mask_account` маскировка данных карт и счетов
- **Маскировка данных карт и счетов** Функция `mask_account_card` маскировка данных карт и счетов
- **Более удобная дата** Функция `get_date` помогает превратить дату в более понятную для пользователя 
- **Фильтрация операций:** Функция `filter_by_state` отбирает словари с нужным статусом (`EXECUTED`, `CANCELED`).
- **Сортировка по дате:** Функция `sort_by_date` выстраивает операции в хронологическом порядке.
* **Фильтрация по валюте:** Функция-генератор `filter_by_currency` фильтрации банковских операций по заданной валюте (например, USD или RUB).
* **Получение описаний:** Функция-генератор `transaction_descriptions` поочередно возвращает текстовые описания для каждой транзакции.
* **Генерация номеров карт:** Функция-генератор `card_number_generator` генерирует номера пластиковых карт в заданном диапазоне с правильным форматированием по 4 цифры через пробел.
## Установка и запуск
1. Клонировать репозиторий.
2. Установить зависимости через Poetry:
   ```bash
   poetry install
   ```
