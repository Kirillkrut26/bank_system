# Виджет банковских операций

## Описание
Проект представляет собой бэкенд-часть для виджета банковского приложения. 
Он умеет фильтровать транзакции по их статусу и сортировать их по дате.

## Функционал
- **Фильтрация операций:** Функция `filter_by_state` отбирает словари с нужным статусом (`EXECUTED`, `CANCELED`).
- **Сортировка по дате:** Функция `sort_by_date` выстраивает операции в хронологическом порядке.

## Установка и запуск
1. Клонировать репозиторий.
2. Установить зависимости через Poetry:
   ```bash
   poetry install
   ```
